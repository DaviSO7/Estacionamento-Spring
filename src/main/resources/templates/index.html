01 / Como funciona

Uma rotina simples.
Um registro por vez.

O controle é feito por quem está na operação. Você confere o veículo; o sistema organiza o registro.

  1. 01

    Identifique

    Informe a placa, o modelo e a cor do veículo. Use as observações quando houver algo a acrescentar.

  2. 02

    Registre

    Confira os dados e registre a entrada. O horário é preenchido pelo sistema ao salvar.

  3. 03

    Consulte

    Encontre a entrada na lista geral do estacionamento, junto aos registros dos demais veículos.

03 / Antes de acessar

O essencial,
sem dúvida.

Entenda o que está disponível antes de começar.

O painel mostra quais veículos? +

Os registros de todos os veículos cadastrados no estacionamento, com placa, modelo, cor, horário de entrada e observações. A lista não representa a ocupação atual ou as vagas disponíveis.

Preciso de uma conta? +

Sim. O cadastro e o login dão acesso às páginas de operação. Se você já tem uma conta, acesse o sistema . Para começar, crie seu acesso .

Quem registra a entrada? +

A pessoa que está operando o sistema informa os dados do veículo e confirma o registro. O horário é preenchido automaticamente ao salvar.

Já é possível registrar a saída? +

Ainda não há registro de horário de saída. Você pode remover um veículo do painel, mas essa ação exclui o registro definitivamente.

Como remover um veículo? +

No painel, escolha Remover ao lado da placa. Confira os dados e confirme. Com JavaScript ativo, você terá 5 segundos para cancelar antes do envio. Após a remoção, o registro não poderá ser recuperado pelo sistema.

Esta demonstração salva alguma informação? +

Não. O formulário desta página apenas atualiza a prévia no seu navegador. Ao recarregar, os exemplos voltam ao estado inicial. Para um registro real, entre no sistema.
